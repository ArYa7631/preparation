# Interview Introduction

## Personal Introduction

### About Me
Yeah, so… I’m Nitesh Arya. I’m currently working as a Lead Engineer at HCLTech, where I get to work on both frontend and backend technologies. My main stack is React.js and Ruby on Rails—I’ve been working with React for about 6 years now and Rails for around 4–5 years. What I really enjoy is making both ends work together properly so the application feels seamless for the end user.

I did my Computer Science degree from SVIET College, Chandigarh. That’s actually where my interest in web development started. I still remember—I won a web design competition there, and it gave me a lot of motivation to take this career path seriously. After that, I picked up React in 2018, then Ruby on Rails in 2019, and I’ve been building with them ever since.

At HCLTech, I’m leading a project for Highspot. We’re working on building multiple microservices using Next.js and Rails. One thing I’m quite proud of is setting up our testing strategy. We use TestCafe for end-to-end tests, RSpec for Rails backend, and React Testing Library for frontend components. Having this setup has really improved our overall code quality and confidence in releases.

Before HCLTech, I worked on some really interesting projects. For example, I built a SaaS platform for doctors and patients, which today serves more than 50,000 users. I also created an investment matching system that connects startups with investors, and a website builder that lets non-technical people create their own landing pages. What I like about these projects is that they solved real problems and were actually useful to people.

Beyond my day-to-day work, I’m very interested in staying updated with the latest technology trends. Especially with React.js and Ruby on Rails, whenever there’s something new, I try to explore it and see how it can be useful. Lately, I’ve also been exploring AI-powered tools like Cursor AI and similar platforms that help developers learn faster and write better code. I find these tools really exciting because they change how we work and speed up development.

In general, I like to focus on making applications fast, reliable, and user-friendly—whether that means optimizing bundle sizes in React, improving database queries in Rails, or setting up automation pipelines. And besides coding, I also enjoy mentoring juniors and helping them grow.

For me, building great software isn’t just about writing clean code. It’s about understanding the business problem, the user needs, and then creating something that really works and brings value.
